### StandardScaler

The StandardScaler scales the data to have a mean of 0 and a standard deviation of 1.

### Formula

The StandardScaler subtracts the mean value per feature from each data point, and then scales the result by the inverse of the standard deviation of each feature.

### Formula

\[ X_{scaled} = \frac{X - \mu}{\sigma} \]

where:
- \( X \) is the original data point
- \( \mu \) is the mean of the feature
- \( \sigma \) is the standard deviation of the feature

### Example

For a feature with a mean of 10 and a standard deviation of 2, the StandardScaler would subtract 10 from each data point and then divide by 2.

\[ X_{scaled} = \frac{X - 10}{2} \]

This ensures that all features have a mean of 0 and a standard deviation of 1, which can improve the performance of certain machine learning algorithms.

### Structure

- **True Positives (TP)**: The number of samples that are correctly classified as positive.
- **False Positives (FP)**: The number of samples that are incorrectly classified as positive when there is no actual positive outcome.

- **False Negatives (FN)**: The number of samples that are incorrectly classified as negative when there is an actual positive outcome.

\[ Accuracy = \frac{TP + TN}{TP + TN + FP + FN} \]
