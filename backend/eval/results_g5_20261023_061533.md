#### Purpose

The primary purpose of the `train_test_split` function is to divide a dataset into two parts: a training set and a test set. The training set is used to train a machine learning model, while the test set is used to evaluate the model's performance.

#### Parameters

The function takes the following parameters:

*   `X`: The feature data.
*   `y`: The target data.
*   `test_size`: The proportion of the data to include in the test set. Defaults to 0.25.
*   `train_size`: The proportion of the data to include in the training set. Defaults to 1 - `test_size`.
*   `random_state`: An integer to control the random seed for shuffling the data. Defaults to 0.

#### Behavior

When called, the `train_test_split` function:

1.  Shuffles the data using the provided `random_state`.
2.  Splits the data into training and test sets based on the provided `test_size` and `train_size`.
3.  Returns the training and test sets, as well as the target data for the training set (`y_train`) and the test set (`y_test`).

### StandardScaler

The StandardScaler scales the data to have a mean of 0 and a standard deviation of 1.

### Formula

The StandardScaler subtracts the mean value per feature on the training set from each data point, and then scales by the inverse standard deviation of each feature on the training set.

### Formula

\[ X_{scaled} = \frac{X - \mu}{\sigma} \]

where:
- \( X \) is the original data point
- \( \mu \) is the mean value per feature on the training set
- \( \sigma \) is the standard deviation of each feature on the training set

### Effect

This scaling ensures that all features have the same statistical properties, which can improve the performance of machine learning algorithms.

`X_scaled = (X - μ) / σ`

- `σ` is the standard deviation of the feature

### Definition and Purpose

A **confusion matrix** is a mathematical table used to evaluate the performance of a classification model. It is a two-by-two array that summarizes the predictions against the actual outcomes.

### Structure

The confusion matrix has the following structure:

|  | Predicted Positive | Predicted Negative |
| --- | --- | --- |
| **Actual Positive** | True Positives (TP) | False Negatives (FN) |
| **Actual Negative** | False Positives (FP) | True Negatives (TN) |

### Components

The components of the confusion matrix are:

*   **True Positives (TP)**: Correctly predicted positive outcomes.
*   **False Positives (FP)**: Incorrectly predicted positive outcomes.
*   **True Negatives (TN)**: Correctly predicted negative outcomes.
*   **False Negatives (FN)**: Incorrectly predicted negative outcomes.

### Interpretation

The confusion matrix provides insights into the performance of a classification model, including:

*   **Accuracy**: The proportion of correct predictions (TP + TN) out of all predictions (TP + TN + FP + FN).
*   **Precision**: The proportion of true positives (TP) out of all predicted positives (TP + FP).
*   **Recall**: The proportion of true positives (TP) out of all actual positives (TP + FN).
*   **F-score**: A weighted average of precision and recall.
